# เริ่มใช้ ZetaCaros 2.0

ติดตั้ง Node.js 24 LTS แตก ZIP ไปโฟลเดอร์ใหม่ ดับเบิลคลิก START-WINDOWS.cmd แล้วเปิด http://localhost:3000 ไม่ต้องใช้ npm install เพื่อเปิดใช้งาน

ครั้งแรกให้ใช้รหัสตั้งค่าจากหน้าต่างเซิร์ฟเวอร์เพื่อสร้างบัญชีเจ้าของร้าน

อ่าน [คู่มือ Windows ภาษาไทย](WINDOWS-TH.md) สำหรับรายละเอียด การสำรอง/กู้คืน การใช้มือถือ และการย้ายข้อมูลรุ่นเดิม ต้นฉบับคู่มือ 1.2 เก็บอยู่ใน original/ZetaCaros-01-business-v1.2.zip
