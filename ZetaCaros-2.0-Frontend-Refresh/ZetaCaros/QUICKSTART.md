# ZetaCaros 2.0 quick start

Use Node.js 24 LTS. Extract to a new folder, double-click START-WINDOWS.cmd, then open http://localhost:3000. No npm install is required for normal use.

Use the setup code printed in the server window to create the first owner account.

Read [README.md](README.md) for features and [WINDOWS-TH.md](WINDOWS-TH.md) for full Windows, backup, mobile HTTPS and migration instructions. The original v1.2 guide remains inside original/ZetaCaros-01-business-v1.2.zip.
